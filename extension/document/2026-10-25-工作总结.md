## 4. 遇到的问题与解决方案

1. **跨域 iframe 注入在用户 Edge 环境静默失败**（`allFrames` + `getAllFrames(frameIds)` 两路都不生效）
   → 改为确定性路径：外壳收集 `contentFrameUrls` → `tabs.create` 临时后台标签 → 顶层文档诊断 → `tabs.remove`。成功抓到 mobilelearn 任务列表真实 DOM。
2. **内容帧正文为空**（XHR 异步渲染，固定 `wait(800)` 太短）
   → 内容帧改为轮询等待正文出现（最多约 6s / 400ms 一次）。
3. **诊断树里看不到课程名**
   → 根因是 `MAX_DEPTH=12` 刚好截断在 `.course-info`（`mainText` 能看到，说明 DOM 有文本），不是页面无数据；深度调至 14，解析器改用 `textContent` 并加回退链。
4. **任务页混入作业类条目，可能误藏未交作业**
   → 向用户确认；用户拍板「已结束直接判定为已完成」；代码保持 `ended`，仅把类型标签改为中性词，并补单测锁死规则。
5. **TypeScript 报错**：`TS2588`（赋值给 const）改 `let`；`TS2322`（`tab.id` 在嵌套闭包收窄失效）→ 提前固化 `const tabId`；诊断缺域权限 → 补 `host_permissions` 与 `matches`。
6. **单测假 DOM 的选择器引擎能力不足**（不支持标签名 / 属性选择器 / 多级后代）→ 扩展 `matches` 与 `queryAll` 实现。
